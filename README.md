# 🐔 AP Daily Poultry Rates (ఆంధ్రప్రదేశ్ డైలీ పౌల్ట్రీ రేట్లు)

ఆంధ్రప్రదేశ్ వ్యాప్తంగా 4 ప్రధాన జోన్ల ఆధారంగా అన్ని జిల్లాల రోజువారీ గుడ్లు మరియు చికెన్ ధరలను చూపే ప్రోగ్రెసివ్ వెబ్ యాప్ (PWA).

## 📌 ముఖ్య ఫీచర్లు
* **4 జోన్ల కవరేజ్:** కోస్తా, గోదావరి, ఉత్తరాంధ్ర, రాయలసీమ జోన్ల వారీగా అన్ని AP జిల్లాల రేట్లు.
* **ఆటోమేటిక్ లెక్కింపు:** 1 గుడ్డు ధర నమోదు చేయగానే 100 గుడ్ల ధర ఆటోమేటిక్‌గా లెక్కించబడుతుంది.
* **ఆటో పుష్ నోటిఫికేషన్లు:** OneSignal ద్వారా తాజా ధరల సమాచారం వినియోగదారులకు వెంటనే చేరుతుంది.
* **ఆఫ్‌లైన్ సపోర్ట్:** ఇంటర్నెట్ నెమ్మదిగా ఉన్నా లేదా ఆఫ్‌లైన్‌లో ఉన్నా క్యాష్ డేటా కనిపిస్తుంది.

## 🛠 ధరలు ఎలా అప్‌డేట్ చేయాలి?
1. GitHub లోని `rates.json` ఫైల్ ఓపెన్ చేయండి.
2. Edit (పెన్సిల్ గుర్తు) నొక్కండి.
3. 4 జోన్ల రేట్లు మార్చి కింద Commit changes నొక్కండి. యాప్‌లో అన్ని జిల్లాలకు వెంటనే ధరలు మారిపోతాయి.
